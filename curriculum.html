CURRICULUM

1年間の学習
ロードマップ

投資未経験から始め、12ヶ月後に自分の「投資ルール」を持った独立投資家へ。5段階の体系的カリキュラムで確実にレベルアップします。

ROADMAP

5フェーズ・12ヶ月の体系的カリキュラム

「知識のインプット → 分析の実習 → コーチとのレビュー → 実践」のPDCAを繰り返しながら、段階的に投資家として成長します。

01
PHASE 1
1〜2ヶ月目
基礎編 — 株式市場の仕組みと投資マインド
「資金管理が投資の9割」という本質を最初に叩き込みます。株式市場の仕組み・注文方法・税金・リスク管理の基本を学び、正しいメンタルセットを構築します。
証券口座の開設と基本設定
主要証券会社の比較・口座開設・取引ツールの使い方
株式市場の仕組み
東証・マザーズ・JASDAQ・市場区分・取引時間・手数料
資金管理とリスク管理
ポジションサイジング・損切りルール・最大ドローダウン管理
投資家のメンタル管理
感情トレードを防ぐルール設定・トレード日誌の付け方
証券口座 市場の仕組み 資金管理 損切りルール トレード日誌
02
PHASE 2
3〜5ヶ月目
テクニカル編 — チャートで売買タイミングを掴む
移動平均線・RSI・MACD・ボリンジャーバンドなどの主要指標を習得。AI株価ダッシュボードのリアルデータを使って、毎日100銘柄のチャートを分析する習慣を作ります。
ローソク足とチャートパターン
陽線・陰線・包み足・はらみ足・三角保ち合い・ブレイクアウト
移動平均線・トレンド分析
5日・25日・75日・200日移動平均・ゴールデンクロス・デッドクロス
RSI・MACD・ストキャスティクス
オシレーター系指標の使い方・ダイバージェンス・シグナル読み取り
出来高分析・板読み
出来高と価格の関係・大口の動きを追う方法・板の見方
RSI MACD 移動平均線 ボリンジャーバンド 出来高 ダッシュボード実習
03
PHASE 3
5〜7ヶ月目
ファンダメンタルズ編 — 決算書を読んで割安株を発掘
PER・PBR・ROE・配当利回り・PSRなど財務指標を使った銘柄スクリーニングを習得。「なぜ安いのか」「なぜ伸びるのか」を数字で語れる投資家になります。
財務三表の読み方
損益計算書・貸借対照表・キャッシュフロー計算書の構造と重要指標
バリュエーション指標の活用
PER・PBR・EV/EBITDA・PSRを使った業種別割安判定
収益性・成長性分析
ROE・ROA・営業利益率・売上成長率・EPS成長率の評価
決算発表の分析と先読み
決算短信の読み方・業績予想の精度評価・サプライズの見つけ方
PER / PBR ROE / PSR 配当利回り 決算短信 スクリーニング ダッシュボード実習
04
PHASE 4
7〜9ヶ月目
ポートフォリオ編 — 分散投資とリスク最小化
個別銘柄の分析力に加え、ポートフォリオ全体のリスク管理を学びます。セクター・規模・相関係数を考慮した資産配分で、相場環境に左右されにくいポートフォリオを構築します。
分散投資の理論と実践
相関係数・効率的フロンティア・最適ポートフォリオ構築の考え方
セクター分析と配分
業種別の景気サイクル・ローテーション戦略・セクター間の相関
リバランスとドルコスト
定期リバランスの方法・ドルコスト平均法の効果・タイミング計画
下落相場での守り方
ヘッジ手法・キャッシュポジションの管理・暴落時の行動ルール
分散投資 セクター分析 リバランス ドルコスト平均法 ポートフォリオ実習
05
PHASE 5
10〜12ヶ月目
実践編 — 自分の投資ルールを確立する
実際の資金を使いながら講師・コーチと一緒にPDCAを回します。「なぜ買うのか」「なぜ売るのか」を言語化し、再現性ある投資スタイルを確立。卒業後も自走できる投資家を目指します。
投資ルールブック作成
エントリー・エグジット・ポジションサイズの自分ルールを言語化
ライブトレード分析会
毎週金曜日の週次振り返り会。実際のトレードを講師と一緒にレビュー
PDCA実践と改善サイクル
コーチとの週次セッションで成功・失敗パターンを分類・改善
卒業後の継続学習計画
卒業後1年間のフォローアップ（エキスパートプラン）・OBコミュニティ参加
実弾トレード PDCA実践 ライブ分析 投資ルール構築 卒業プロジェクト

LEARNING TOOLS

学習に使うツール・教材

🗂️
AI株価ダッシュボード
毎日更新。東証上場100銘柄超のスコア・RSI・PER・PBR・ROE・配当利回り・52週高安値データを一画面で確認。テクニカルとファンダメンタルズを統合分析できる独自ツール。
📹
動画講義ライブラリ
累計200本超の動画講義（1本15〜45分）を収録。スマートフォン・タブレット・PCで受講可能。全て字幕付き。倍速再生対応で学習効率を最大化。
📋
トレード日誌テンプレート
専用のGoogleスプレッドシートテンプレートで取引履歴・感情・判断根拠を記録。コーチが毎週レビューし改善点をフィードバック。
💬
Slack コミュニティ
受講生専用Slackで銘柄情報・分析・市況を共有。コーチへの質問もチャンネルで可能。他の受講生の分析から学ぶことも多い。
📊
バーチャルポートフォリオ
実弾トレード前の練習に使う仮想ポートフォリオ。実際の株価データを使って擬似的に売買を経験し、自分のルールをテストできる。
📄
週次マーケットレポート
毎週月曜日に配信される市場環境レポート。注目セクター・決算スケジュール・テクニカルポイントを講師が解説。週の学習方針を立てるのに活用。
